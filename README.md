# ArtCraft Launcher: English UI evidence

Source commit: c4989a87859c061fd5f9dd0058e2fe078d72be76

Rendered from the real egui UI with language explicitly set to English and synthetic app/release data. No personal settings, downloads, logs or installed application data are included.

Captures cover version selection and pinning, confirmed MSI downgrade, table action menus, portable install location, release dropdown and transient-error retry.

Screenshots are hosted separately from the feature branch to keep generated PNGs out of the production code diff. ArtCraft names, icons and logos are reproduced as supplied by the upstream application.
